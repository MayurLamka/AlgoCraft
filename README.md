# DSA Coding Platform

A full-stack **Data Structures and Algorithms (DSA) Coding Platform** designed to help students practice programming problems, write and execute code, submit solutions, and learn from explanations.

The platform also includes an **Admin Panel** for managing coding problems, test cases, and solutions.

---

## 🚀 Features

### 👨‍💻 User Features

- User registration and login
- Secure authentication using JWT
- Browse DSA problems
- View problem statements
- Write code using an online code editor
- Run code against custom test cases
- Submit solutions
- Automatic code compilation and execution
- Test case-based judging system
- View submission results
- View official solutions
- Track problem-solving progress
- Support for multiple programming languages

### 🛠️ Admin Features

- Admin authentication
- Add new DSA problems
- Edit existing problems
- Delete problems
- Add and manage test cases
- Add problem solutions
- Manage code templates
- Manage platform content

### ⚙️ Judge System

The platform contains an automated judging system that:

1. Receives the user's submitted code
2. Compiles the code
3. Executes the program
4. Runs it against test cases
5. Compares the output with the expected output
6. Determines whether the solution is correct
7. Returns the result to the user
